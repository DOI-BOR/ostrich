Algorithms - Gauss Marquardt Levenberg (GML)

The OSTRICH Gauss Marquardt Levenberg (GML) optimization algorithm

Initial Publication:

April 11, 2021

Modified:

April 11, 2021

The following optional group will configure the Gauss-Marquardt-Levenberg algorithm and will be processed if [ProgramType] is set to “Levenberg-Marquardt”. 

BeginLevMarAlg
DerivativeType             [deriv_type]
StepSize                   [step_size]
StepScale                  [step_scale]
StepTolerance              [step_tol]
MinimumLambdas             [min_lambdas]
MaximumIterations          [max_iters]
ConvergenceTolerance       [conv_tol]
EndLevMarAlg

Figure 1: General Format of the Gauss-Marquardt-Levenberg Group

Where BeginLevMarAlg and EndLevMarAlg are parsing tags that wrap the following set of algorithm configuration variables:

  • DerivativeType: The finite-difference scheme used to estimate the Jacobian. Supported values are “FirstForward”, “FirstBackward”, and “FirstCental” (central difference; note that this value must be spelled “FirstCental”, not “FirstCentral”, to be recognized). The default is “FirstForward”.
  • StepSize: The finite-difference step used when perturbing each parameter to estimate the Jacobian, expressed as a fraction of the parameter’s current value. The perturbed value is clamped to the parameter’s lower/upper bound, so a very large step size simply evaluates the Jacobian at the bound. This value is also scaled down (by StepScale) as the solution converges. There is no practical built-in default (the coded default is effectively infinite) so this value should be specified by the user.
  • StepScale: The factor by which StepSize is divided once the convergence criteria for an iteration (see ConvergenceTolerance) have been met. The default is 2.
  • StepTolerance: A parameter is excluded from the Jacobian/line-search for an iteration if perturbing it (per StepSize) would change it by less than this fraction of its range. The algorithm also stops once StepSize falls below this tolerance. The default is 0.
  • MinimumLambdas: The minimum number of step-size multipliers (lambdas) tried during the line-search portion of each iteration. The actual number of lambdas used is the larger of this value and the number of available parallel compute slots. The default is 1.
  • MaximumIterations: The maximum number of Jacobian/line-search iterations performed by the algorithm. The default is 0, meaning this value must be specified by the user in order for the algorithm to run.
  • ConvergenceTolerance: The algorithm convergence value – the step size is reduced when the relative reduction in the objective function (i.e. phi, Φ) over an iteration is less than or equal to this value. The default is 0.

References

Levenberg, K. 1944. A Method for the Solution of Certain Problems in Least Squares. Quarterly of Applied Mathematics 2, 164-168.

Marquardt, D. 1963. An Algorithm for Least-Squares Estimation of Nonlinear Parameters. SIAM Journal on Applied Mathematics 11, 431-441.
