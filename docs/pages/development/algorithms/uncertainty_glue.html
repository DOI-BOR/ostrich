Algorithms - Generalized Likelihood Uncertainty Estimation (GLUE)

The OSTRICH generalize likelihood uncertainty estimation (GLUE) uncertainty algorithm

Initial Publication:

April 11, 2021

Modified:

November 8, 2026

This algorithm seeks to identify behavioral parameters set by randomly sampling and evaluating alternative parameter sets. The following optional group will configure the GLUE algorithm and will be processed if [ProgramType] is set to “GLUE”. 

BeginGLUE
SamplesPerIter    [nper]
NumBehavioral     [nsols]
MaxSamples        [nevals]
Threshold         [fmax]
EndGLUE

BeginGLUE
SamplesPerIter    10
NumBehavioral     10
MaxSamples        100
Threshold         1000
EndGLUE

Figure 1: General Format (left) and Example (right) of the GLUE Group

Where BeginGLUE and EndGLUE are parsing tags that wrap a set of algorithm configuration variables. These variables are described below:

  • SamplesPerIter: The number of random samples generated and evaluated in each iteration. The samples of an iteration are evaluated concurrently by the available workers. This variable also controls the frequency of output within the OSTRICH run record: the current best solution and the current number of behavioral solutions that have been discovered will be reported after every iteration. The default value is 10.
  • NumBehavioral: The desired number of behavioral solutions. The GLUE algorithm will halt if the desired number of behavioral solutions has been found or if the computational budget (i.e. MaxSamples) has been exhausted. The default value is 10.
  • MaxSamples: The maximum number of model evaluations allowed before the GLUE search is terminated. Samples are evaluated in complete iterations, so the number of evaluations is rounded up to the next multiple of SamplesPerIter. The default value is 100. However, studies have shown that GLUE can require 100,000 or more evaluations to discover a sufficiently representative number of behavioral samples.
  • Threshold: The threshold for separating behavioral and non-behavioral parameter sets. Parameter sets with corresponding objective function values less than the threshold will be considered behavioral. The default value is 1000.

The following behaviors apply to the GLUE algorithm in the development version of OSTRICH:

  • Sampling: Each parameter is sampled uniformly between its lower and upper bounds (in the transformed space). Integer parameters are rounded before evaluation, and the rounded values are reported.
  • Retained samples: The best NumBehavioral samples are retained, whether or not they are behavioral. The search ends when every retained sample is behavioral, or when MaxSamples has been reached.
  • Output: The run record in OstOutput0.txt lists the best solution and the number of behavioral solutions found after each iteration. The optimal parameter set, the algorithm metrics and the retained samples (best first) are written at the end of the analysis. The objective function of every model evaluation is recorded in the OstModelN.txt file of the processor that evaluated it.
  • Warm start: The WarmStart option is not available for GLUE. A warning is logged and a new analysis is performed.
