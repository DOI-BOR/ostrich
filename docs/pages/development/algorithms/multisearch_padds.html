Algorithms - Pareto Archived DDS (PADDS)

The OSTRICH Pareto Archived DDS multi-objective optimization algorithm

Initial Publication:

April 11, 2021

Modified:

November 8, 2026

The following optional group will configure the multi-objective Pareto Archived DDS algorithm and will be processed if [ProgramType] is set to “PADDS”. 

BeginPADDSAlg
PerturbationValue      [r_val]
MaxIterations          [budget]
SelectionMetric        [metric]
EndPADDSAlg

BeginPADDSAlg
PerturbationValue      0.2
MaxIterations          50
SelectionMetric        Random
EndPADDSAlg

Figure 1: General Format (left) and Example (right) of the PADDS Group

Where BeginPADDSAlg and EndPADDSAlg are parsing tags that wrap a set of algorithm configuration variables. Alternatively, BeginPADDS and EndPADDS may be used as the parsing tags. PADDS configuration variables are described below:

  • PerturbationValue: This parameter defines the standard deviation of the decision variable perturbations as follows: PerturbationValue = StdDev / DV_Range. The allowable range is 0 to 1. As the value increases, the sampling becomes more and more spread out from the current best value of the decision variable. The default and recommended value is 0.2.
  • MaxIterations: The computational budget in terms of the number of objective function evaluations. Users need to set this input for each problem according to how long each objective function evaluation takes and how quickly an answer is needed. The more objective functions you use, the better your estimate of the globally optimal solution will be. The default value is 50.

  • SelectionMetric: This metric for scoring non-dominated solutions when seeding DDS trials within the overall PADDS algorithm. Values currently supported are listed below:

    • Random
    • CrowdingDistance
    • EstimatedHyperVolumeContribution
    • ExactHyperVolumeContribution

    The default selection metric value is “ExactHyperVolumeContribution”. For a discussion on choosing the appropriate selection metric see Asadzadeh and Tolson (2013).

Initial parameter sets may be supplied using the optional BeginInitParams group, with one parameter set per line. These parameter sets are evaluated before the random initial solutions and count towards MaxIterations.

The following behaviors apply to the PADDS algorithm in the development version of OSTRICH:

  • Objectives: The objectives are the weighted sum of squared errors (WSSE) of each observation group, so the ObjectiveFunction must be WSSE and each objective requires its own observation group. Other objective functions (e.g. GCOP) are not yet supported.
  • Initialization: The user-specified initial parameter sets are followed by max(5, 0.5% of MaxIterations) uniformly random solutions, limited so that MaxIterations is not exceeded. The initial solutions are evaluated concurrently by the available workers.
  • Search: Each subsequent candidate depends on the result of the previous candidate, so candidates are evaluated one at a time. A candidate whose objectives match those of a non-dominated solution is discarded as a duplicate.
  • Integer parameters: Integer parameters are rounded before evaluation, and the rounded values are archived and reported.
  • Output: Each time a new non-dominated solution is found, the non-dominated solutions are written to the run record in OstOutput0.txt and to OstNonDomSolutions0.txt. The perturbation probability of each DDS step is written to OstPADDSPn.txt. The final non-dominated and dominated solutions and the algorithm metrics (including the number of discarded duplicates) are written at the end of the analysis. The objectives of every model evaluation are recorded in the OstModelN.txt file of the processor that evaluated it.
  • Warm start: The WarmStart option is not available for PADDS. A warning is logged and a new analysis is performed.
  • Not yet supported: The PreserveBestModel option is not available for multi-objective algorithms. A warning is logged and the option is disabled.
