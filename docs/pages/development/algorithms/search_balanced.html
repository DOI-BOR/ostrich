Algorithms - Balanced Exploration/Exploitation Random Search

The OSTRICH balanced exploration/exploitation random search optimization algorithm

Initial Publication:

April 11, 2021

Modified:

November 8, 2026

The following optional group will configure the experimental BEERS algorithm and will be processed if [ProgramType] is set to “BEERS”. 

BeginBEERS
NumSamples  [nsamp]
EndBEERS

BeginBEERS
NumSamples   25
EndBEERS

Figure 1: General Format (left) and Example (right) of the BEERS Algorithm Group

Where BeginBEERS and EndBEERS are parsing tags that wrap the following set of algorithm configuration variables:

  • NumSamples: the number of samples evaluated by the algorithm (i.e. computational budget). Values less than 1 are replaced with 1.

The following behaviors apply to the BEERS algorithm:

  • Each candidate depends on the objective of every previously evaluated sample, so samples are evaluated one at a time. When OSTRICH is run with multiple MPI processes, only one model evaluation is in progress at any time.
  • The first sample is selected randomly within the parameter bounds; the initial parameter values are not used.
  • Integer parameters are rounded before evaluation, and the rounded values are used in the archive.
  • The archive of every evaluated sample is written to OstArchive.txt, including the final sample.
  • Warm start (WarmStart) and the extraction of initial parameter values from model output ("extract") are not available. If requested, a warning is logged and a new analysis with a random first sample is performed.
